# Segurança

A versão mantida é a mais recente da branch `main`.

Não abra uma issue pública com credenciais, dados pessoais ou detalhes exploráveis. Use **Security > Report a vulnerability** neste repositório e informe impacto, reprodução mínima e versão afetada.

Tokens, chaves e credenciais não pertencem ao código, logs, issues ou exemplos. Revogue imediatamente qualquer segredo exposto.
